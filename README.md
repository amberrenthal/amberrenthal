# Amber Renthal — Engineering Portfolio

Open index.html locally to preview. Upload index.html, style.css, script.js, resume.pdf and README.md directly to the root of your GitHub Pages repository. Under Settings > Pages, select Deploy from a branch, main, / (root), and Save.

The resume PDF omits the personal phone number for public posting. Contact links use the email and LinkedIn supplied in the resume. Project drawings are illustrative schematics, not actual project images. To add photos, place image files beside index.html and replace a project-art SVG with an img element and descriptive alt text.
