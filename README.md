# Amber Renthal — Portfolio

Open `index.html` in a browser to preview. Keep `style.css` and `script.js` beside it.

## Customize before publishing
- Edit the About, Projects, Work Experience and Skills sections in index.html. All example projects, roles and skills are placeholders, not verified credentials.
- Replace an illustrative project SVG with `<img src="images/project.jpg" alt="Description of your project" style="width:100%;height:100%;object-fit:cover">` and create an images folder containing that photo.
- Add resume.pdf and follow the comment in the Resume section to enable the download. Remove private addresses/phone numbers if desired.
- Add public email and LinkedIn links in Contact. Only publish project photos and details you have permission to share.

## Publish with GitHub Pages
1. Create a public repository named YOURUSERNAME.github.io.
2. Upload index.html, style.css, script.js, README.md and any assets directly to the repository root (not inside another folder). Commit.
3. In Settings > Pages, select Deploy from a branch, main, / (root), Save.
4. Your site will be at https://YOURUSERNAME.github.io/ once deployment succeeds.

No frameworks, dependencies, or build commands required.
